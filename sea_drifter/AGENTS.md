# 海岛拯救开发约束

以 GDD_v0.9.md 为规则来源。引擎 Godot 4，目标 Web。美术为原创像素风，不使用参考游戏的素材。

1. 不得实现"自动防御评分制"或"每日自动防御判定"。
2. 不得实现"延长天数"机制。
3. 不得让"所有岛满级"成为胜利条件。
4. 不得实现其他岛屿的快进播放视角、画中画或分屏。
5. 不得实现跨岛资源运输或运输上限。
6. 不得为远端岛单独写"抽象演算模型"或任何状态折算函数。
7. 不得在 `IslandWorld` 中按 `island_id` 写分支逻辑。
8. 存档只允许在 Day 状态写入。
9. 不得实现黄昏（Dusk）独立状态。
10. 不得实现居民死亡。
11. 不得实现"夜晚提前结束"或"跳过夜晚剩余时间"。
12. 不得让研究点来自完美防御或击杀。
13. 不得把修复做成读条；不得给非待收复状态的修复取消 25% 每日上限。
14. 不得允许夜晚拆除建筑。
15. 不得在没有建造居民时开放建造菜单；**不得允许玩家本人替代建造居民施工**。
16. 不得把防御塔 / 通讯塔 / 火炮塔 / 迫击炮塔实现为四个独立建筑。
17. 不得让空高塔拥有任何攻击力。
18. **不得让高塔承载超过 3 名驻守者，或承载不同职业的混编。**
19. **不得让高塔（无论空塔还是有人）失去"视作城墙"的阻挡属性。**
20. 不得让电力变成可消耗资源。
21. 不得让远程体无视城墙。
22. 不得让敌人每帧重选目标（每 0.25 秒一次即可）。
23. 不得让科技树任何节点解锁兵种或高塔形态（兵种只能来自协同）。
24. 不得让居民树任何节点解锁兵种、高塔形态或提供电力/建筑。
25. 不得让协同提供任何建筑、资源、电力、人口或数值加成。
26. 不得实现"无人版的协同塔形态"（例如自动迫击炮阵列）。
27. 不得让高塔或协同形态消耗电力。
28. 不得让英雄驻守高塔。
29. **不得实现"通讯 2"或任何告急自动弹窗**——通讯只有 0 和 1 两级，告急只靠侧栏变红闪烁。
30. **不得让一局可获得的研究点超过或少于 30。**
