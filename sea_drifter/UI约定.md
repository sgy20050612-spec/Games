# v0.0.5 界面约定

- 右上角日夜钟显示天数和游戏时刻。角色与物品页集中显示资源、人口、生命和电力，下方为 36 格物品栏。
- 设置采用浅橙色像素面板，提供音量滑条、显示下拉选项和独立的界面与场景缩放。
- 原创像素风：参考《王国：两位君主》的水面、日落、夜间暖光；参考《星露谷物语》的场景和物件可读性。
- 居民调度：左侧无业居民合并成一整列，列内标注所属岛屿；中间建造生产、资源收集、战斗三列；右侧岛屿编号与名称。
- 拖拽居民时播放跑动；转职立即改变职业外貌。未解锁自由转职时保留固定职业限制。
- 点击某岛某职业单元格打开设施分配页，上方为设施名称，下方为居民分配，可在设施间拖拽。
- 科技树三栏：左科技、中央协同、右居民；右上研究点；解锁边缘分别蓝/红/黄，未解锁灰色。
- 协同分别在第二、三、四级，两侧箭头指向中央。第三级下方绘制分界区域；第四级之后中央留空。
- 地图显示群岛与右侧岛屿列表，当前岛屿用绿色轮廓高亮。
