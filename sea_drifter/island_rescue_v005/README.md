# 海岛～拯救！ v0（0.0.4）

依据 GDD v0.9 制作的首个可玩版本。默认入口为主菜单和真实新游戏，不加载美术展示场景。

## 操作与规则

WASD/方向键移动；E救援和交互，按住E采集；靠近工匠按B打开建造，左键放置建筑或攻击，右键取消建造；点击建筑查看详情。
U在核心旁升级，F吃食物回血，Tab/Esc打开菜单。
时间按游戏时钟固定推进：白天100秒、入夜2秒、夜晚80秒。白天最后20秒自然呈现日落；数字1/2/3不会切换时间。菜单和结算按策划案暂停。
初始为第1天、主岛1级、木0/石0/铁0/食物20、无已解锁科技进阶、尚未救出居民。先采集木头、石堆，救援无业居民并在Tab调度中分配职业。
居民拖拽调度，职业格进入设施分配；右键居民可选择已解锁兵种和装备。固定职业到居民树6级才可自由转职。
基地与玩家成长、两条树与协同、高塔三人驻守、电力、三岛并行波次、码头交通、收复、十夜结算、BE/NE/HE、十个存档槽均已接入。
v0使用独立存档目录 island_rescue_v0，避免把早期展示状态当作正式存档。

Godot4.7.2，逻辑分辨率1152×648，默认GL Compatibility。远端 /home/guangyaoshen/games/island-rescue，SSH别名ubuntu-fyp（D3020-A3）。
本次变化与操作见变更说明_v0.0.3.md。城墙左键起点→移动鼠标→左键确认；右键取消。难民营每天补充居民。
