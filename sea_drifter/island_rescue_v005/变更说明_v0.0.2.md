# v0.0.2 变更说明

本次用户要求优先于GDD原始人口与资源设定。

1. 新游戏木/石/铁为0，食物20。地图包含木头堆、树木、石堆、铁矿、浆果，按住E采集，建造必须实际扣材料。新一天资源点补满；已被建筑占用的位置不刷新。
2. 废墟、聚落、副岛与难民营救援的普通居民均为无业；普通人口奖励也先进入无业池。获救后当日即可Tab→居民调度，拖到本岛对应职业格。英雄保持专属身份。
3. 每岛设置固定难民营，初始2人，每天新增2人，营地等待上限6人。靠近按E逐个救援；全球人口已满时不消耗营地人数。
4. 工匠通过格点寻路前往墙外施工位，完工后保持墙外位置，旧存档中卡墙的工匠也会移出碰撞区。
5. 施工到场后播放挥锤与碎屑动画；修墙保留瞬时修复规则，另播放短暂锤击反馈。
6. 城墙改为左键选起点→移动鼠标预览整线与总材料→再次左键确认。右键取消。单次最多40段，格点连续；障碍、通路限制、材料或建筑上限不满足时整线拒绝，不部分扣料。确认后工匠依次施工；初期仍需玩家在工地附近，科技6可离岛自动施工。

验证：23项新规则、7项图形UI专项、98基础、30后期/存档、422规则、18个真实开局与出海流程、14调度UI、15水面检查通过，共627个检查点。
